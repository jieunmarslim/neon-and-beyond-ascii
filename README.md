# Neon and Beyond — Interactive ASCII Canvas

Full-bleed interactive floating ASCII art canvas with 2D open-ocean shallow-water ripple physics, press-and-hold logo submersion, a solo rotating 3D Mars deep-space mode with orbiting spacecraft sun phases and ASCII shooting stars, and slow auto-rotation across 7 patterns.

Built with **Gemini 4 Neon**.

## Patterns
- **Google Cloud** — Official 2025 gradient cloud logo
- **Google** — Official 2025 circular 4-color gradient G logo
- **Gemini** — Official 2025 4-point 4-color gradient Gemini star
- **Mars** — Solo rotating 3D Mars in deep space with orbiting spacecraft camera phases, distant ASCII Sun, eclipse rim glow, and click-to-launch ASCII shooting stars (20s hold)
- **Angel** — Winged angel with 12-frame flapping motion and halo
- **Neon & Beyond** — Full-ASCII typographic banner in Gemini 4-color gradient
- **JAPAC** — Full-ASCII `JAPAC CLOUD TECHIES` typographic banner

## Build & Run

```bash
python3 scripts/build.py
open index.html
```
